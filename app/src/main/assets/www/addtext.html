Adding Text

Open sub menu for adding all available textual annotations.

Select the type of text you want to add.
Touch screen and move crosshairs to place it. Dependent of the type of text a dialog opens to let you enter the text and properties.

1. Lyric

Text to sing along with the music can be placed under the note systems. Max. two lines of lyrics can be added.

2. Textblock

Text blocks are for more that text didn't find place under the note system. They can only be placed beneath the score.
Move the crosshairs anywhere at the end of you song for the dialog to open.

Text blocks can be rearranged by dragging them on each other!

3. Annotations

In addition to specialized musical annotations, this one lets you place any textual annotation. Textual annotations can be placed above the note system.
