Editing your score

Score Elements

Each score consists of various musical elements.

Currently available elements are:
  1. Title block with songname, composer and date
  2. Textual annotation
  3. Chord designation
  4. Notes and Rests
  5. Lyrics placed below measure
  6. Graphical annotations like Coda and Segno
  7. Text blocks placed under the score
  8. Measures, containing most of the other elements
  9. Page break, only visible in editing mode

Bottom Bar

In edit mode the bottom bar gets displayed at the end of the screen. It Allows you to move, select, edit and delete all elements that make up a score. Notably notes, rests, chords and textual annotations.

The Bottom Bar consists of the following elements:

1. Selection Arrows

Select next or previous element of same kind.

2. Control Pad

Allows you to move selected items in the desired direction.

3. Select Button

Touch the hand icon to activate the selection mode. Select items by touching them.

4. Edit Items

Open option dialog for selected item with this button. Double tapping works also on most elements.

5. Delete Items

Delete previously selected items.

Elements Drawer

Open the Elements Drawer by swipe in from the left side, or by clicking the symbol in the left corner of the Action Bar

The Elements Drawer provides you with all the elements that make up a score. Select any element and click somewhere in the score to add it at this position. Once selected, you can add this element multiple times. The last selected element gets displayed in the upper left corner of the Action Bar.

1. Notes and Related

Add notes, rests and notes related elements.

See Adding Notes for more.

2. Chords

Add chord annotations to the score. Select type of chord to add in opening dialog.

3. Text

Add different types of text.

See Adding Text for more.

4. Adding Annotations

Add different types graphical of annotations.

See Adding Annotations for more.

5. Measures

Add measures at any place of the score. Select number and features of measures to add in opening dialog.

See Adding Measure for more.
