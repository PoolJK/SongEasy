Notes and Related

Open sub menu for adding notes, rests and related.

1. Notes

Select for adding notes. Dialog that shows up as you touch somewhere in the score for selecting the length.

See Edit Note for note options.

2. Rests

Select for adding rests. Dialog that shows up as you touch somewhere in the score for selecting the length.

See Edit Rest for rest options.

3. Ties

Add note ties to a previously selected note. The tie is displayed if there is a next note in the system with the same pitch.

4. Beam Start

Add a beam start property to the selected note. The beam is displayed if a note is following with a beam continuous or stop property

5. Beam Continue

Add a beam continue property to the selected note.

6. Beam Stop

Add a beam stop property to the selected note. The beam is displayed if a note is preceding with a beam start or continuous property
