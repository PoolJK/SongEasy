Dialog for adding or editing measure

Add or edit measures.


Available properties for measure:
  1. Number of measures to add, only available in adding mode
  2. Measure layout properties:
    1. Start a new line
    2. Show repeat start bracket, first measure in adding mode
    3. Show repeat stop bracket, last measure in adding mode
    4. Show end bracket, last measure in adding mode
    5. Add page break, last measure in adding mode
  3. Add key change
  4. Add time change
